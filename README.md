# 🌱 AI Crop Recommendation System

An AI-powered web application that recommends the most suitable crop based on soil nutrients and environmental conditions using Machine Learning.

---

## 🚀 Features

* Crop Prediction using Machine Learning
* Confidence Score
* Fertilizer Suggestion
* Crop Image Display
* Simple Web Interface

---

## 🛠️ Tech Stack

* Python
* Flask
* Scikit-learn
* Pandas
* NumPy
* HTML/CSS
* Gunicorn
* Render Deployment

---

```bash

```

